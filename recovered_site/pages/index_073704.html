Main Capsule Structure

 

This set of files is the main structure. The instructions are probably not as good as previous ones but, by now, the builder should be able to follow along. Print out the Main_files.pdf  first. There are almost 500 pieces to this structure. If you build it like the photos, you'll need to punch out and glue on an additional 240 fasteners on the lower clamp ring. Let me know how it goes. I suspect there are some errors...
