Antenna Fairing

The first set of files will be everything you need to build the Antenna Fairing as shown below. It was a challenging place to start. It's an odd part that most people don't get to see as the flown capsules lost theirs during descent. The first release will not include the internal wiring but it will be added later. I would really like some feedback. If  I don't get any, I may not post the instructions for the remainder of the project.

Some of the files may be large so be patient. All the files are listed on the first page of the instructions. These files should be dated 10/31/06.
